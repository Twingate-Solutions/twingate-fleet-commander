Manual overrides

Overrides honor the floor and drain-before-delete. Every action is audit-logged.

Floor-fill: manually removing or replacing a connector below min_connectors only triggers FC to auto-fill the Remote Network back up to the floor on the next cycle. To keep the Remote Network smaller, lower min_connectors and restart the manager instead.

The override secret travels in the X-FC-Override-Secret request header — only enable overrides behind a TLS-terminating proxy (or over loopback), never over plain HTTP on an exposed interface.
